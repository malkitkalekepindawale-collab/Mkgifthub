# MK Gift Hub — Free Website

This is a simple static website for MK Gift Hub.

## Free publishing
Recommended: GitHub Pages.
1. Create a GitHub account.
2. Create a public repository named `mkgifthub`.
3. Upload `index.html` and `style.css`.
4. In Settings → Pages, choose the main branch as the publishing source.
5. Your free site will be available at a GitHub Pages address.

Replace the emoji product placeholders with your real product photos when ready.
